## 현재 검수 화면에 적용되는 방식

- 백엔드 GET 단일 상세·70문항 묶음 응답에
  `stem_display`, `group.instruction_display`,
  `group.passage_text_display`, `choices[].display_text`,
  `transcript.display_text`를 추가했다.
- 화면에서는 공통 지시문과 공통 지문을 교정된 표시값으로 출력한다.

  원본 승인 내용을 사용자가 알지 못하는 사이에 저장하거나,
  36회 전체 v6 원자적 마이그레이션 전에 일부만 저장하는 위험을 차단한다.
- 새 백엔드는 기존 18736과 격리된 **18737 포트**에서도 실행·읽기 전용
  조회를 검증했다. 36회 L001·L007, 35회 L001의 교정 미리보기와
  원본 DB 텍스트 보존을 확인했다. 기존 18736 검수 서버와 탭은 유지해
